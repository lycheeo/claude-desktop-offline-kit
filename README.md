# Claude Desktop 离线安装精简包

已有 CC Switch、Claude CLI 的 Windows 11 x64 电脑：只补装 Claude Desktop。

下载 minimal.zip，解压后照「安装步骤.md」操作。

仅包含 Desktop 4.23118.1.0、配套 host CLI 2.1.321、两份安装/修复脚本与一页说明。不包含 CC Switch、Python、硬件工具、账号、密钥或公司网关地址。

离线安装后仍需自己的模型接口；不包含 Cowork 虚拟机。第三方组件归原作者，本仓库不是官方发行。

请到 [Releases](https://github.com/lycheeo/claude-desktop-offline-kit/releases) 下载。
